# Hong Jung Ah · Game UI/UX & Unity

홍정아의 게임 인터페이스 포트폴리오. 기존 포트폴리오 원본에서 추출한 화면을 프로젝트별 가로 갤러리와 UX 설계 설명으로 소개합니다.

## Development

Node.js 22 이상이 필요합니다. 외부 npm 의존성은 없습니다.

```sh
npm run dev
npm test
npm run build
```

`data/portfolio.json`은 공개 콘텐츠이며 `assets/`는 최적화한 이미지입니다. 이미지 클릭 시 왼쪽 확대 화면과 오른쪽 설명을 제공하고, 키보드 탐색과 모션 감소 설정을 지원합니다. 갤러리 아래에는 설계 요약과 엔진 적용·리소스 자료 두 칸이 표시됩니다. 자료는 숨겨진 편집기에서 추가할 수 있고, 2MB 이하 GIF는 애니메이션을 유지합니다. 한글은 자체 호스팅한 Noto Sans KR을 사용하며 라이선스는 assets/fonts/OFL.txt에 있습니다.

배포는 GitHub Actions에서 검사 후 GitHub Pages로 진행합니다. 인증 정보는 소스·포트폴리오 데이터·브라우저 저장소에 저장하지 않습니다. 로컬 편집에서는 PC의 GitHub CLI 인증을 사용하며 인증 정보는 브라우저에 전달되지 않습니다.

게임 화면과 포트폴리오 이미지는 제작자의 작업물이며, 사이트 코드의 공개가 이미지 재사용 권한을 의미하지 않습니다. 화면에 포함된 외부 캐릭터·배경 등 아트의 권리는 각 권리자에게 있습니다.
